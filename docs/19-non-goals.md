# Non-goals and deferred scope

These are deferred to protect contract and quality, not because the products cannot be built in parallel.

## Phase 0 non-goals

- pixel-perfect reproduction of competitor interfaces;
- arbitrary autonomous code self-modification;
- marketplace or public plugin execution;
- broad multi-agent swarms inside each product;
- x402 in local capabilities;
- mobile parity;
- real-time multi-user CRDT collaboration;
- direct publishing to every platform;
- training large foundation models;
- universal file-format parity;
- unbounded memory of user content.

## Toolshape Voice early non-goals

- replacing every accessibility/input method on every operating system at once;
- silent operation in secure/password fields;
- perfect dictation in every game, elevated process, remote desktop, or anti-cheat environment;
- retaining raw audio indefinitely by default;
- claiming sensitive personality/profession conclusions from speech.

## Toolshape Studio early non-goals

- complete After Effects/Premiere/DaVinci/Figma/Illustrator/Canva/CapCut parity;
- 3D modelling;
- professional colour grading and full DAW functionality;
- arbitrary third-party effect binaries;
- full browser-based collaborative suite before the local editor is stable;
- flattening generated work into images when structured editability can be preserved.

## Permanent prohibitions

- copying proprietary competitor code, prompts, assets, templates, or distinctive branded layouts;
- letting model output bypass policy or domain validation;
- storing plaintext credentials in prompts, vectors, logs, or project files;
- claiming deletion or privacy guarantees that the system cannot technically and contractually prove;
- describing source-available code as open source when the licence is not open source.
