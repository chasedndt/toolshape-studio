# Public outcome baseline — Canva

**Sources accessed:** 14 July 2026  
**Primary pages:** `canva-visual-suite`, `canva-magic-layers`, `canva-connect-apis`, `canva-apps-sdk`

## Publicly documented outcomes

Canva’s current Visual Suite positions multiple content formats—documents, email, sheets, whiteboards, presentations, social, photo, video, websites, print—inside one connected, AI-enabled product. It emphasises templates, assets, brand management, collaboration, import, insights, and AI assistance throughout the workflow.

Magic Layers is particularly relevant: it frames a flat/static or AI-generated image as an editable starting point by recovering text, objects, background, grouping, and layout relationships into a multi-layer design.

Canva also exposes developer APIs and an Apps SDK. Therefore, an agent-native competitor cannot differentiate merely by adding a REST API or MCP wrapper.

## Toolshape implications

1. Combining design and video into Toolshape Studio is consistent with market movement toward one connected creative workflow.
2. Structured editability is a core differentiator: generated work must remain layered, typed, and refinable.
3. The canonical scene/timeline model must be deeper than an external automation API.
4. Templates, components, brand/style tokens, variants, data binding, imports, and review belong in the shared Studio project.
5. Agent plans should create editable structures, not only final images.
6. Human refinement remains a primary workflow; the agent should not trap the user in reprompting.

## Clean-room boundary

Do not copy Canva templates, assets, icons, product copy, or distinctive screens. Use public outcome categories to create an original domain and editor.
