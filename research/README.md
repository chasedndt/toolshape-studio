# Research archive

This directory captures the evidence used to shape the architecture and product requirements. It does not archive copyrighted books or reproduce full papers. It stores source metadata, compact notes, design implications, uncertainty, and a refresh process.

## Files

- `SOURCES.json` — machine-readable source index
- `READING-PACK.md` — ordered reading programme
- `methodology.md` — source and inference discipline
- `research-refresh-workflow.md` — ChaseOS proposal workflow
- `product-notes/` — current public product outcome baselines
- `benchmark-notes/` — evaluation implications
- `paper-notes/` — agent, security, and design research synthesis

## Evidence labels

```text
Official specification
Official product documentation
Government/standards guidance
Peer-reviewed research
Academic preprint
Open-source project documentation
Book/practitioner source
Inference/proposal
```

Every architecture claim should distinguish evidence from inference. Competitor pages define public outcomes, not source code or a licence to reproduce distinctive interfaces.

## Update rule

Product and protocol pages are dated at access. Before implementation, release, or book publication, run the refresh workflow and preserve a dated note of changes.
