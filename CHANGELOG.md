# Handover change log

## v2 — 14 July 2026

This is a structural rewrite of the earlier draft.

### Portfolio

- Replaced three separate creative products with two independent products.
- Combined the Canva-style design domain and CapCut-style video domain into **Toolshape Studio**, one content-creation super app.
- Renamed the voice workstream to **Toolshape Voice** and rejected `Voquill` as a working name after exact-name GitHub collision checks.

### ChaseOS model

- Corrected the hierarchy to ChaseOS → agent harnesses → MCP/SDK/HTTP/CLI adapters → semantic application kernels.
- Separated ChaseOS supervisory responsibilities from harness planning/tool execution.
- Added a standalone mode for users who do not run ChaseOS.

### Architecture

- Distinguished operation envelopes from vectors, memory, preferences, and style profiles.
- Added ANAC schemas, examples, capability manifests, policy objects, secret handles, jobs, artifacts, provenance, and workflow recipes.
- Added dynamic task-specific interface constraints.

### Security

- Replaced an unrealistic “detect, encrypt, then permanently delete everything” claim with a defensible secret-broker and retention architecture.
- Added explicit limitations for remote processors, backups, endpoint compromise, screenshots, clipboard history, crash dumps, and model-provider retention.

### Products

- Expanded Toolshape Voice to system-wide Windows insertion, hotkeys, language/provider selection, correction learning, analytics, milestones, privacy, and agent access.
- Added a 21-feature 80/20 baseline for Toolshape Studio covering design, image, video, audio, captions, keyframes, effects, agent workflows, and operator review.
- Added style-personalization architecture and self-evolving coaching without unconstrained self-modifying software.

### Research and evaluation

- Added a dated source index and reading pack.
- Added OSWorld, OSWorld-MCP, WindowsWorld, AppWorld, tau-bench, AgentDojo, and prompt-injection-inspired evaluation requirements.
- Added a research-refresh proposal workflow for ChaseOS.


## v2.1 — dual Codex and Discord launch packet

- Added two isolated Codex session prompts for parallel Platform/Voice and Studio implementation.
- Added Windows worktree bootstrap and optional two-session Codex CLI launcher.
- Added Discord control-plane category, routing, permission and structured-event prompt.
- Added control-plane event schema, example and shared workstream protocol.
